# Throwing Discs 3.1.4 — Wind-Charged Crafting & Duration
Minecraft Java 1.21.11 · Fabric

## Новое в 3.1.4: Длительность и заряд ветра

- **Длительность I–III** — новое зачарование для любого из пяти дисков (стол зачарований или книга + наковальня).
- Каждый уровень добавляет **+3 игровых тика прямого полёта** и **+3 блока допустимой дальности**. Возвращение к игроку работает как раньше.
- Базовая дальность и время полёта уменьшены; с **Длительностью III** диск летит немного дальше, чем до обновления.
- **Заряд ветра** теперь обязателен для медного, железного, золотого и алмазного диска: он помещается в **центр** рецепта. Незеритовый по-прежнему улучшается из алмазного диска в кузнечном столе.

### Новый рецепт диска (4 материала + 1 заряд ветра)

```text
  М
М З М
  М
```

**М** — медный, железный, золотой слиток или алмаз; **З** — заряд ветра.

| Диск | Базовая дальность | С Длительностью I | II | III |
|---|---:|---:|---:|---:|
| Медный | 8 блоков | 11 | 14 | 17 |
| Железный | 11 блоков | 14 | 17 | 20 |
| Золотой | 10 блоков | 13 | 16 | 19 |
| Алмазный | 14 блоков | 17 | 20 | 23 |
| Незеритовый | 16 блоков | 19 | 22 | 25 |

*Дальность в таблице — верхний предел пройденного пути от броска; столкновения и предельное время полёта могут завершить полёт раньше.*

## Новое в 3.1.3 — подсказки крафтов

Теперь рецепты открываются автоматически при подборе материалов, как в ванильном Minecraft:

- **Медный диск** — после получения медного слитка.
- **Железный диск** — после получения железного слитка.
- **Золотой диск** — после получения золотого слитка.
- **Алмазный диск** — после получения алмаза.
- **Незеритовый диск** — после получения незеритового слитка, алмазного диска или шаблона улучшения незерита.

Minecraft покажет стандартное уведомление **«Открыты новые рецепты!»** и добавит соответствующий рецепт в книгу. Эти рецепты (кроме незеритового улучшения) находятся во вкладке снаряжения верстака; незеритовый диск ищи в кузнечном столе.

В уже существующем мире, где материал был получен раньше, переложи соответствующий материал в пустой слот или выброси и подбери заново, чтобы вызвать обновление инвентаря. При отключённом показе уведомлений подсказка не появится, но рецепт откроется.


## Новое в 3.1.2: взаимодействия с миром

- Попадание диска разбивает **обычное, цветное, тонированное стекло и стеклянные панели**. Разрушение воспроизводит стандартный эффект блоков, стекло не выпадает.
- Попадание разбивает **декорированные горшки (вазы)** с сохранением их содержимого и осколков, а также **цветочные горшки с растениями**.
- Попадание по **колоколу** заставляет его звонить (блок остаётся цел).
- Хрупкие блоки **не расходуют рикошет**: диск продолжает лететь после разрушения блока.
- Это работает и при ускоренном полёте от зачарования «Порыв ветра».
- Редактируемый набор стеклянных блоков: `data/throwingdiscs/tags/block/disc_shatterable_glass.json`.


**3.1.1:** плавное перемещение и вращение дисков между тиками с помощью интерполяции `item_display`. Игровая механика не изменена.

## Как получить полную сборку с музыкой
Аудиофайлы из предоставленного архива импортируются **отдельно**, потому что через текущий GitHub-коннектор невозможно загрузить большие двоичные OGG в репозиторий.

1. Открой GitHub-репозиторий → **Add file → Upload files**.
2. Загрузи в корень проекта **оригинальный ZIP с пятью OGG** без распаковки. Имена внутри архива менять не надо.
3. Нажми **Commit changes**.
4. GitHub Actions найдёт этот ZIP, извлечёт дорожки в `src/main/resources/assets/throwingdiscs/sounds/music/`, соберёт JAR и проверит запуск сервера.
5. На странице успешной сборки в **Artifacts** скачай `ThrowingDiscs-3.1.4-MC1.21.11`.
6. Извлеки `ThrowingDiscs-MC1.21.11-3.1.4.jar`, замени прежний JAR в `.minecraft/mods`.

**Без пяти OGG GitHub Actions публикует отдельный артефакт `ThrowingDiscs-3.1.4-MC1.21.11-preview-NO-MUSIC` для проверки анимации. В нём музыкальные файлы отсутствуют, поэтому для полноценного воспроизведения нужно загрузить исходный ZIP и использовать обычную сборку `ThrowingDiscs-3.1.4-MC1.21.11`.**

### Локальная сборка
```bash
python3 tools/import_music.py "твой-архив.zip"
gradle clean build
```

## Проверки
GitHub Actions компилирует код и запускает выделенный сервер. Эти проверки **не подтверждают реальное звучание** в игровом клиенте; воспроизведение нужно проверить в Minecraft.

Используй оригинальные музыкальные записи только при наличии необходимых прав на их публикацию и распространение.
