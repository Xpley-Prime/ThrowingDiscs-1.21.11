# Throwing Discs — Fabric for Minecraft Java 1.21.11

Исходный код мода с пятью метательными дисками: медный, железный, золотой, алмазный, незеритовый.

## Сборка
На вкладке **Actions** выбери **Build Fabric Mod** и запусти **Run workflow**, либо используй Java 21 и Gradle 9.2.1+: `gradle build`.
При успешной сборке JAR будет доступен в **Actions → Artifacts** или локально по пути `build/libs/throwingdiscs-1.0.0.jar`.
Потребуются Fabric Loader и Fabric API для Minecraft 1.21.11.

## Управление и механики
ПКМ — бросок диска. Диск пробивает несколько целей, рикошетит от твёрдых блоков и возвращается в руку/инвентарь. Параметры зависят от материала. Для крафта положи четыре слитка соответствующего металла или алмаза ромбом (верхняя, нижняя, левая и правая ячейки). Незеритовый диск — улучшение алмазного в кузнечном столе.

**Статус:** исходники не были скомпилированы или протестированы в игре. Если GitHub Actions сообщит об ошибке, понадобится исправить совместимость API.
