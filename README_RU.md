# Throwing Discs — Java 1.21.11 (Fabric)

**Версия 2.0 — переработка по трейлеру Mojang от 14.11.2026.**

## Что изменено
В отличие от первого прототипа, летящий диск — **собственный тип снаряда** со своей физикой, столкновениями и сохраняемым предметом, а НЕ выброшенный предмет `ItemEntity`.

- ПКМ из основной или второй руки, бросок и возврат предмета.
- Реальное **пробивание нескольких врагов** на одной линии; один враг не получает урон повторно от того же диска.
- Рикошеты от твёрдых блоков, в том числе пола и стен; отскоки продлевают время полёта.
- Срабатывание ванильных блоков-мишеней (`target`) и других блоков, реагирующих на `Projectile.onProjectileHit`.
- **Вращающийся диск** с лёгким покачиванием: отдельная vanilla `item_display`-сущность показывает текстуру в полёте. Снаряд имеет свой серверный хитбокс.
- Плавно изменяющаяся траектория возвращения, звуки попаданий и возврата.
- Все пять твоих оригинальных текстур: медь, железо, золото, алмаз, незерит.
- Креатив не дублирует диск; сохранение состояния снаряда при выгрузке чанков; предмет дропается при выходе из игры/смерти владельца.

**Статус:** механики реконструированы по ролику. Официальные точные величины урона, прочности, длительности полёта и крафта Mojang ещё не опубликовала, поэтому ниже — авторские параметры.

## Рецепты

Медь, железо, золото, алмазы: положи 4 соответствующих слитка/алмаза ромбом в верстаке:

```text
. X .
X . X
. X .
```

Незеритовый диск: **кузнечный стол** + шаблон улучшения незерита + алмазный диск + незеритовый слиток.

## Как установить
Установи Fabric Loader и Fabric API под Minecraft Java **1.21.11**, затем положи только собранный JAR в `.minecraft/mods/`.

## Получить JAR через GitHub
Открой **Actions → Build Fabric Mod → последний зелёный запуск → Artifacts → ThrowingDiscs-Fabric-1.21.11**. Из ZIP достань JAR.

Локальная сборка: JDK 21 + Gradle 9.2.1+: `gradle build`. Готовый файл: `build/libs/throwingdiscs-1.0.0.jar`.

## Проверка в игре
```mcfunction
/give @s throwingdiscs:copper_disc
/give @s throwingdiscs:iron_disc
/give @s throwingdiscs:golden_disc
/give @s throwingdiscs:diamond_disc
/give @s throwingdiscs:netherite_disc
```

Сценарии: бросок в 3 зомби по одной линии; отражение от стены; удар о пол; попадание в `target` с красной пылью; бросок из второй руки; бросок в упор; выход из мира во время броска; заполненный инвентарь; последний пункт прочности; творческий режим.

Полное совпадение с ещё не выпущенным официальным предметом невозможно гарантировать по одному видео. Числа и анимация являются попыткой максимально близко воспроизвести анонс.
