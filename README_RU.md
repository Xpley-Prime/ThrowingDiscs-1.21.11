# Throwing Discs — v3.0.0 · Fabric · Minecraft Java 1.21.11

## Enchantments Update
В игре снова ровно пять дисков: медный, железный, золотой, алмазный, незеритовый. Медовый и слизневый предметы и их рецепты удалены. Особые способности теперь доступны всем дискам через зачарования.

| Зачарование | Уровни | Механика |
| --- | --- | --- |
| **Откид** | I–III | Сильнее отбрасывает существ при попадании метательного диска. |
| **Прилипание** | I | Подбирает **все** выпавшие стопки предметов, которых касается диск по пути туда и обратно; доставляет при возврате игроку. При заполнении инвентаря остаток выпадает около игрока. |
| **Отскок** | I–III | Добавляет +1/+2/+3 рикошета к базовым рикошетам диска. |
| **Порыв ветра** (*Wind Burst*, ванильный) | I–III | При первом удачном попадании по мобу создаёт без разрушения блоков ветровой импульс, отбрасывает существ рядом, с увеличенной скоростью направляется к ближайшему **другому** мобу и затем возвращается. Если другого моба нет — возвращается сразу. |
| **Острота**, **Небесная кара**, **Бич членистоногих**, **Заговор огня**, **Отдача** и др. | Ванильные | Расширенная совместимость со столом и наковальней; ванильный бонус урона/отбрасывания/огня применяется при попадании снаряда. Также «Прочность», «Починка», «Проклятие утраты». |

**Получение чар:** «Откид», «Прилипание», «Отскок» доступны в столе зачарований и при объединении книг в наковальне. Ванильный **Порыв ветра** по-прежнему является редким чаром из зловещего хранилища (можно переносить с книги на диск в наковальне). Перезаписан только список подходящих предметов этого ванильного зачарования; его поведение на булаве остаётся ванильным.

### Рецепты обычных дисков
Четыре слитка соответствующего металла или четыре алмаза ромбом. Незеритовый диск — улучшение алмазного в кузнечном столе.

### Команды
```mcfunction
/give @s throwingdiscs:copper_disc
/give @s throwingdiscs:iron_disc
/give @s throwingdiscs:golden_disc
/give @s throwingdiscs:diamond_disc
/give @s throwingdiscs:netherite_disc
```

### Сборка
JDK 21 + Gradle 9.2.1: `gradle clean build`.
Результат: `build/libs/ThrowingDiscs-MC1.21.11-3.0.0.jar`.
Через GitHub: **Actions → Build and smoke-test Fabric mod → последний запуск → Artifacts → ThrowingDiscs-3.0.0-MC1.21.11**.

Важно: сборка и запуск выделенного сервера автоматически проверяются в CI, но **не подменяют** тестирование реального боя и механики зачарований с клиентом.

### Изменения версий
- 3.0.0: удалены honey/slime диски; добавлены три зачарования, ванильный Wind Burst на дисках, зачарования оружия, перенос всех собранных предметов, новое имя JAR/артефакта.
- 2.2: исправление преждевременного возврата медового диска; 5 рикошетов слизневого.
- 2.1: экспериментальные медовый и слизневый диски.
- 2.0: собственная сущность снаряда и рикошеты.
