# PALIMPSEST 0.3.0 — Runeforge

## Критические исправления
- Перо Палимпсеста теперь в творческом инвентаре в разделе инструментов.
- Новым игрокам показываются подсказки; книга на K содержит пошаговый учебник.
- Полный постраничный Tab-атлас для всех рун с золотыми точками начала.
- Исправлены переполнения интерфейса на высоком GUI scale.
- Добавлены недостающие переводы имён BlockItem на русском и английском.
- Восстановлена работа заклинаний по жидкости: луч учитывает воду.
- Жесты разбиты на один непрерывный штрих, упрощён Иней, добавлена интерполяция точек.
- Улучшено распознавание зашумлённых жестов и фильтрация случайных каракулей.

## Система магии
- 27 базовых знаков: 6 намерений, 13 стихий, 8 оттенков.
- 702 формулы с реальными пространственными действиями.
- Преобразования грунта и камня, заморозка, посадка, создание и удаление некоторых блоков.
- Широкие волны, дорожки, столпы, расширенный радиус и временные печати.
- Объёмные частицы, окружности, лучи, несколько звуков на заклинание.

## Графика
- Сменены шаблонные 16px рисунки на 32px силуэтную пиксельную графику.
- Отдельные 32px текстуры верха и боковых сторон 28 магических устройств.
- Переработан внешний вид пера.

## Проверка
- Автоматические тесты распознавателя всех рун и случайных линий.
- Проверка Minecraft-ресурсов, рецептов и текстур.
- Запуск реального Fabric dedicated server в CI.
- Ручное визуальное тестирование клиента по-прежнему требуется.
