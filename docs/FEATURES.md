## Ещё одна система, не вошедшая в 100

**Живой язык рун:** 3 намерения × 4 стихии × 4 варианта модификации = 702 композиций. В каждой формуле сервер распознаёт переданные игроком траектории вместо доверия готовым ID.

## Игровая навигация

- `K` — иллюстрированный справочник, вкладки 1–4, листание стрелками.
- `/palimpsest catalogue` — количество и разделы.
- `/palimpsest tools [страница]`, `stations [страница]`, `rituals [страница]` — доступные механики.
- Для выживания предусмотрены рецепты всех 32 инструментов и 28 сооружений; для творческого режима — соответствующие разделы инвентаря.

## Проверка доступности

`gradle build` компилирует реальное игровое поведение, создаёт исходные пиксельные текстуры, проверяет тесты распознавателя и упаковывает игровые ресурсы. GitHub Actions дополнительно проверяет количество 33 предметных (включая перо) и 28 блочных PNG, наличие рецептов и запуск выделенного Minecraft-сервера.
