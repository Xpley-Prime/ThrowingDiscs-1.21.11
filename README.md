# ✦ PALIMPSEST — Чернила Мироздания

**Minecraft Java 1.21.11 · Fabric · Java 21 · версия 0.2.0**

Магия здесь не выбирается кнопкой. Возьми перо и **нарисуй начертания мышью вручную**: сначала намерение, затем стихию, затем — по желанию — дополнительный оттенок. Траектория распознаётся **на сервере**, поэтому нельзя подменить рисунок сетевым пакетом с названием заклинания.

Помимо каллиграфической магии реализован самостоятельный набор из **100 разных игровых действий**: 32 предмета, 28 функциональных сооружений и 40 материальных ритуалов. Они не считаются за счёт вариаций обычных заклинаний. [Полный каталог с описаниями](docs/FEATURES.md).

## Быстрый старт

1. Установи Fabric Loader (не ниже 0.18.4) и совместимый Fabric API для Minecraft **1.21.11**.
2. Положи JAR из успешной сборки GitHub Actions в `mods` (не `-sources.jar`). Для мультиплеера мод нужен и на сервере, и у клиента.
3. Получи перо командой `/give @s palimpsest:scribe_quill` либо скрафти его.
4. Возьми перо в основную или вторую руку и нажми **G**.
5. **ЛКМ с удержанием** — нарисовать один непрерывный символ. Начало — золотая точка в справочнике, отпустить ЛКМ — подтвердить знак.
6. Нарисуй два символа и нажми **Enter**. Третий символ необязателен.
7. **Backspace** — отменить знак; **R** — очистить; **Tab** — полный атлас; **Esc** — закрыть.

### Руны и их грамматика

| Роль | Символы | Результат |
|---|---|---|
| Намерение | Нить (стрела), Ореол (круг), Волна (W) | Луч в цель, ловушка-печать, магическая волна |
| Стихия | Уголь, Прорастание, Иней, Завеса | Огонь и урон, лечение/рост, заморозка, левитация |
| Оттенок | Отголосок, Отражение, Цена | Повтор, инверсия, двойная сила с потерей здоровья |

Получается 48 сочетаний; они **не входят** в каталог 100 других механик. Одна руна = один непрерывный штрих. Рисуй её максимально близко к образцу; длина и небольшое вращение допускаются.

### Игровая книга чернил

Нажми **K** в мире, чтобы открыть отдельный справочник по всем разделам. **1–4** выбирают вкладку (руны, инструменты, сооружения, ритуалы), стрелки листают страницы. Ничего не нужно запоминать наизусть.

Команды:
- `/palimpsest guide` — базовая помощь по рунам.
- `/palimpsest mana` — текущий запас чернил.
- `/palimpsest catalogue` — сводка содержания.
- `/palimpsest tools 1`, `/palimpsest stations 1`, `/palimpsest rituals 1` — списки и ID.

### Магические инструменты

32 самостоятельных предмета с ПКМ-способностями: рывок, заморозка воды, призыв воды, выращивание посевов, обжиг, поиск руды, управление погодой, магнит предметов, маяк возвращения, временный мост и другие. Каждый предмет имеет рецепт и собственную пиксельную иконку. Для проверки можно использовать `/give @s palimpsest:blink_needle`.

### Магические устройства

28 полноценных блоков, размещаемых в мире и взаимодействующих с игроком. Примеры: чернильный колодец, горн починки, резонатор руды, ледяной алтарь, золотой ректификатор, купель очищения, источник прилива. Для проверки: `/give @s palimpsest:ritual_altar`. У блоков есть крафты, модель, собственная текстура и дроп при добыче.

### Ритуалы с материалами

Установи **Алтарь переплёта**, держи катализатор в основной руке и нажми ПКМ по алтарю. Материал расходуется только если обряд сработал. Например, `minecraft:bone` призывает волка, `minecraft:apple` создаёт саженец, `minecraft:echo_shard` повторяет предыдущий ритуал, а `minecraft:gunpowder` создаёт взрыв без разрушения блоков. Все 40 катализаторов описаны в [каталоге](docs/FEATURES.md).

## Правила и сохранение

- До **100 чернил**, восстановление 4 единицы в секунду; заклинания, предметы и устройства расходуют их.
- Рисование и исполнение контролирует сервер: проверяются форма линий, текущий предмет, стоимость и задержки.
- Действие зависит от времени и погоды (ночь, дождь, солнце).
- Чернила, точки возвращения и память последнего ритуала сохраняются в каталоге мира `palimpsest/state.properties`, периодически и при закрытии сервера.
- Некоторые ритуалы воздействуют на мобов и блоки в мире: перед использованием на общем сервере убедись, что это разрешено правилами сервера.

## Сборка

Исходники доступны в ветке `palimpsest-1.21.11`. Для локальной сборки нужен JDK 21 и Gradle 9.2.1: `gradle build`. Под Windows можно использовать `build.bat`, под Linux / macOS — `build-linux.sh`.

Готовый JAR — `build/libs/palimpsest-0.2.0.jar`. Отдельный `-sources.jar` содержит исходники и не подходит для `mods`. GitHub Actions собирает JAR, проверяет юнит-тесты, созданные PNG и рецепты, а также проверяет запуск выделенного сервера.

Графика 60 новых предметов и сооружений генерируется собственным исходным кодом Gradle-задачи `generateArcaneArt` в виде настоящих 16×16 PNG, которые включаются в мод при сборке.

### Границы версии 0.2.0

Начертания пока рисуются в экранном интерфейсе поверх мира, а не непосредственно на стенах и земле; печати в мире существуют на время действия эффекта. Пассивные магические устройства пока активируются взаимодействием, а не через сложные многоблочные энергетические сети. Это реальные ограничения текущей реализации, а не скрытые заглушки. Новые функции должны проверяться в игре отдельно от успешной CI-сборки.
