# ✦ PALIMPSEST — Чернила Мироздания

**Версия 0.3.0 · Minecraft Java Edition 1.21.11 · Fabric · Java 21**

Вся магия строится на собственноручных рисунках: проведи мышью три или два отдельных жеста. Сервер заново распознаёт реальные линии. В меню нет кнопок, которые колдуют вместо тебя.

## Первые пять минут

1. **Найди перо.** В творческом режиме — вкладка **Инструменты и приспособления**. В выживании скрафти по рецепту или для проверки используй `/give @s palimpsest:scribe_quill`.
2. **Нажми G**, держа перо в любой руке.
3. Первый символ — **намерение**. Нарисуй стрелку «Нить», ведя ЛКМ без отрыва. Начинай с золотой точки в атласе.
4. Второй символ — **стихия**. Попробуй «Иней»: нарисуй Z одним штрихом.
5. Посмотри на воду и нажми **Enter**. Если цель доступна, она превращается в лёд.

Клавиша **K** открывает большую книгу магии с пошаговыми инструкциями, примерами всех 27 рун, 32 предметами, 28 сооружениями и 40 ритуалами.

**Tab** на экране рисования открывает полный атлас. **1 / 2 / 3** переключают намерения, стихии и оттенки, **← / →** листают страницы, Tab возвращает к рисунку. **Backspace** удаляет предыдущую руну, **R** очищает формулу, **Esc** закрывает.

Образцы рун нельзя выбрать кликом: нужно **нарисовать самому**. Никаких отрывов ЛКМ внутри одной руны. Если руна не узнаётся, рисуй её крупнее в пределах квадрата и внимательно следи за золотой начальной точкой.

## Новый магический язык

- **6 намерений:** Нить (луч), Ореол (печать), Волна (вокруг игрока), Разлом (область перед игроком), Плетение (магическая дорожка), Столп (вертикальная сила).
- **13 стихий:** Уголь, Жизнь, Иней, Завеса, Камень, Прилив, Гроза, Сияние, Тень, Пространство, Корень, Металл, Ветер.
- **8 оттенков:** Эхо, Обратность, Жертва, Точность, Широта, Долголетие, Якорь, Тишина. Оттенок можно не добавлять.

Итого **6 × 13 × 9 = 702 формулы**. Каждая имеет реальное серверное исполнение, но влияние некоторых сочетаний зависит от целевой поверхности, погоды, времени суток и наличия существ. Чары не гарантируют изменение любой поверхности: они изменяют конкретные подходящие блоки.

### Примеры, взаимодействующие с миром

| Рисунок | Результат |
|---|---|
| Нить + Иней | Заморозить воду или остудить лаву, если целишься в неё |
| Разлом + Корень | Превратить участок земли в мох |
| Разлом + Жизнь | Вырастить растения и оживить почву |
| Столп + Камень | Создать вертикальные участки булыжника на свободных местах |
| Плетение + Сияние | Проложить светящуюся дорожку из светоблоков |
| Разлом + Прилив | Создать воду на доступной территории |
| Нить + Уголь | Превратить песок в стекло или поджечь доступное место |
| Разлом + Тень | Изменить травяной грунт на мицелий |
| Нить + Металл | Переработать блок необработанной меди |
| Разлом + Ветер | Сместить упавшие предметы и сдуть снег и огонь |
| Ореол + Гроза | Поставить печать, активирующуюся при подходе существа |
| Нить + Иней + Обратность | Растопить ледяной блок |

Для площадных воздействий используй **Разлом**, для пути — **Плетение**, для вертикального построения — **Столп**. Оттенок **Широта** расширяет воздействие, **Точность** усиливает и сужает, **Тишина** экономит чернила и убирает звук.

Заклинания сопровождаются пульсами частиц, кругами, лучами, магическими следами и несколькими звуками. Мод использует стандартные звуки Minecraft; отдельный оригинальный саундтрек не добавлен.

## 100 других механик

В дополнение к каллиграфии сохранён отдельный набор **32 магических предметов, 28 функциональных блоков и 40 материальных ритуалов**. Это **не** 100 перекрасок одной руны. Полный список и команды смотри в [каталоге функций](docs/FEATURES.md).

Предметы применяются ПКМ в руке; устройства — ПКМ по установленному блоку; ритуалы — ПКМ по Алтарю переплёта с подходящим катализатором в основной руке. Расходуются магические чернила и, для ритуалов, материал.

Команды: `/palimpsest guide`, `/palimpsest mana`, `/palimpsest catalogue`, `/palimpsest tools 1`, `/palimpsest stations 1`, `/palimpsest rituals 1`.

## Текстуры и интерфейс

В версии 0.3.0 предметы получили новые **32×32 силуэтные пиксельные иконки** с различающимися формами: перья, иглы, крюки, флаконы, талисманы, часы и амулеты. Каждая из 28 магических станций получила две 32×32 текстуры: гравированный верх и архитектурные боковые панели. Всё генерируется исходной Gradle-задачей `generateArcaneArt` и упаковывается в JAR.

Холст подстраивается под масштаб GUI, а атлас и книга листаются — никакие руны не должны пропадать из списка из-за размера окна.

## Установка

1. Minecraft **1.21.11** + Fabric Loader (не ниже 0.18.4) + совместимый Fabric API.
2. Скачать артефакт **Palimpsest-1.21.11-jar** с успешного запуска [GitHub Actions](https://github.com/Xpley-Prime/ThrowingDiscs-1.21.11/actions?query=branch%3Apalimpsest-1.21.11).
3. Распаковать ZIP. Положить **`palimpsest-0.3.0.jar`**, а не `-sources.jar`, в `mods`.
4. В мультиплеере мод должен быть и у клиента, и у сервера.

Сборка из исходников: JDK 21 + Gradle 9.2.1, команда `gradle build`. GitHub Actions компилирует, проверяет руны, содержимое JAR, загрузку рецептов и запуск выделенного Minecraft-сервера.

## Ограничения, без скрытых обещаний

- Начертания пока рисуются в **двумерном экранном холсте**, а не на трёхмерных стенах. Блоки мира и существа изменяются реально, но сетка символов не приклеивается к поверхности.
- Печати и отложенное Эхо не переживают перезапуск сервера; запас чернил, личная точка возвращения и память ритуала сохраняются.
- Широкая зона магии ограничена по радиусу сервером, чтобы одно действие не разрушало огромные чанки.
- Успешный серверный smoke test не доказывает, что каждый предмет, UI-масштаб и графический эффект вручную проверен в клиенте. Для проверки визуальных деталей нужны игровые испытания.

Ветка `palimpsest-1.21.11` развивается независимо от мода Throwing Discs.
