# ✦ PALIMPSEST — Чернила Мироздания

**Minecraft Java Edition 1.21.11 / Fabric / Java 21**  
**Версия проекта:** 0.1.0, прототип с исходным кодом.

В Палимпсесте нет меню выбора заклинаний. Игрок берёт перо, нажимает **G**, рисует линии мышкой поверх мира и самостоятельно строит магическую фразу. Каждая фраза — это **намерение → стихия → необязательный оттенок**. Сервер получает именно набор нарисованных точек, распознаёт их самостоятельно и выполняет заклинание, если оно действительно написано.

## Как начать играть

1. Поставь Fabric Loader для Minecraft **1.21.11** и совместимый **Fabric API**.
2. Получи перо командой `/give @s palimpsest:scribe_quill` или скрафти его: осколок аметиста в верхнем правом слоте, перо в центре, огненный стержень в нижнем левом.
3. Возьми **Перо Палимпсеста** в основную или вторую руку, нажми **G**.
4. Зажми левую кнопку мыши и нарисуй **один символ одним непрерывным росчерком**, отпусти кнопку, чтобы зафиксировать его. Первый знак — намерение, второй — стихия.
5. **Enter**: сотворить полученную формулу. Можно перед этим добавить третий знак (оттенок).
6. **Backspace**: убрать предыдущую руну; **R**: очистить страницу; **Esc**: закрыть; `/palimpsest guide`: получить мини-справочник в чате; `/palimpsest mana`: узнать запас чернил.

### Начертания (10 рун)

| Разряд | Руна | Как выглядит | Смысл |
|---|---|---|---|
| Намерение | **Нить** | горизонтальная стрелка одним росчерком | Избирательный луч на существо или блок перед игроком |
| Намерение | **Ореол** | замкнутый круг | Печать на земле, срабатывающая при приближении существ |
| Намерение | **Волна** | большая буква W | Магический импульс во все стороны от игрока |
| Стихия | **Уголь** | две вершины огня | Горение и магический урон |
| Стихия | **Прорастание** | плавная буква S | Исцеление; при наведении на растение — костная мука |
| Стихия | **Иней** | зигзагообразный снежный кристалл | Замедление и замерзание |
| Стихия | **Завеса** | спираль к центру | Левитация и подсветка существа |
| Оттенок | **Отголосок** | горизонтальная восьмёрка | Повторить заклинание с задержкой |
| Оттенок | **Отражение** | песочные часы одним росчерком | Изменить стихию на противоположную (лечить ожоги, ускорять вместо замедления...) |
| Оттенок | **Цена** | молния | Значительное усиление за дополнительные чернила и 1 сердце здоровья |

**Совет:** на правой стороне экрана рисования появляется маленький атлас доступных знаков, нарисованный линиями; золотая точка показывает рекомендуемое начало штриха. Старайся использовать большую часть квадрата. Размер и небольшое вращение почерка несущественны. Сходство после каждого штриха показывается в процентах. Сильнее написанный символ даёт больше силы.

Три намерения × четыре стихии × четыре варианта оттенка (включая его отсутствие) = **48 программируемых комбинаций**, а также несколько контекстных вариантов от окружающего мира.

### Примеры формул

- **Нить + Уголь**: прицельное воспламенение врага; если попадания нет, остаётся визуальный след на месте удара.
- **Волна + Иней + Отголосок**: два разнесённых по времени импульса, замедляющих окружающих существ.
- **Ореол + Уголь + Цена**: усиленная огненная печать с риском для здоровья заклинателя.
- **Нить + Прорастание**: направленное лечение живого существа или ускорение роста растения перед игроком.
- **Нить + Иней + Отражение**: ускорение и согревание вместо заморозки.
- **Ореол + Завеса**: невидимое охранное начертание, которое подбрасывает первого вошедшего в него врага в воздух.

### Резонанс мира

Мир — часть заклинания. Сила **Угля** увеличивается днём под открытым небом; **Прорастание** получает бонус в дождь; **Иней** — под дождём или в воде; **Завеса** — ночью. Если росчерк сделан точно, это тоже усиливает эффект. Игрок может выбирать момент и место для магии, а не только формулу.

### Чернила и баланс

У каждого игрока до **100 единиц магических чернил** (восстанавливаются со скоростью **4 ед./сек.**). Базовая формула стоит 12, печать +8, отголосок +9, отражение +6, цена +17. Между заклинаниями есть короткая задержка. Третий символ не обязателен. В режиме творчества проверка стоимости снимается, но остальные ограничения работают. Магические печати и отложенные повторы рассчитываются на стороне сервера.

**Осторожно:** текущий прототип действует на любых живых существ, кроме заклинателя для волны и печати, включая дружественных мобов и других игроков. Печати временные и существуют в памяти сервера, пока он работает.

## Как собрать исходники

**Нужны:** Java JDK **21**, интернет для первого получения Gradle, Minecraft и Fabric-зависимостей.

### Windows

Запусти **`build.bat`** двойным щелчком или через консоль. Скрипт скачает официальный Gradle 9.2.1 (если его ещё нет) и выполнит `gradle build`.

### Linux / macOS

```bash
chmod +x build-linux.sh
./build-linux.sh
```

Можно также установить Gradle 9.2.1 самостоятельно и выполнить `gradle build` из корня проекта.

Итоговый мод должен появиться в `build/libs/palimpsest-0.1.0.jar`. Это **ожидаемый результат сборки**, а не файл, уже включённый в архив. Файл с `-sources.jar` — исходники, не мод для папки `mods`.

### Проверка алгоритма распознавания без Minecraft

```bash
bash test-recognizer.sh
```

Этот тест требует только Java 21, компилирует независимое ядро жестов и запускает **600 сценариев** с шумом, масштабированием и вращением, **900 тестов отклонения случайных каракулей**, а также проверяет протокол передачи линий и некорректные входные данные.

### Лаборатория рисования — без загрузки Minecraft

На **Windows** запусти `gesture-lab.bat`, на **Linux / macOS** — `./gesture-lab.sh`. Откроется отдельное окно Java Swing с тем же самым математическим движком распознавания и образцами рун. Рисуй мышкой, нажимай **Enter**, чтобы увидеть формулу, **Backspace** для отмены, **R** для очистки. Это именно тестовый инструмент, **не замена Minecraft-моду**.

### CI

В `.github/workflows/build.yml` есть GitHub Actions workflow: при загрузке проекта в репозиторий он пытается собрать мод на Java 21 и сохраняет JAR как артефакт. **Workflow в этом архиве не запускался.**

## Что действительно реализовано в исходниках

- Ввод непрерывных штрихов мышью, экран над игрой, визуализация чернил и справочный атлас.
- Распознавание собственноручного почерка по нормализованной траектории с устойчивостью к изменению масштаба, смещению и небольшому повороту.
- 10 рун, разрядная грамматика, необязательные модификаторы и 48 сочетаний.
- Серверная пересборка смысла каждой переданной линии; ограничения на размер пакета, число точек, диапазон координат, стоимость, наличие пера и кулдаун.
- 3 вида действия (луч / импульс / временная печать), 4 стихии, 3 модификатора, инвертированные эффекты.
- Магические частицы, звук, контекстные усилители, восстановление и синхронизация чернил.
- Изменение роста растений, задержанное повторение магии, одноразовая ловушка, сила, зависящая от качества начертания.
- Локализация названия предмета и клавиши, текстовые подсказки, крафт, пиксельная текстура пера.

## Известные ограничения прототипа

- **Полная Gradle-сборка и запуск в клиенте Minecraft в среде подготовки архива не выполнялись:** сеть для загрузки Fabric/Minecraft недоступна. Проверен и скомпилирован отдельно только движок распознавания. Внешние вызовы Minecraft могут потребовать мелких исправлений после первой реальной сборки.
- Линии рисуются **поверх изображения игрового мира**, не прикрепляются к физической поверхности блоков в 3D. Печати отображаются частицами в мире.
- Запасы чернил, активные печати и задержанные заклинания **не сохраняются на диск** после перезапуска сервера.
- Нет квестов, боссов, исследования руин, мировых событий и персональной книги истории магии; они задуманы как дальнейшие системы.
- Распознаватель в этой версии поддерживает **один непрерывный штрих на символ**, а не произвольную многолинейную каллиграфию.

## Как развивать дальше

**Версия 0.2 — живая каллиграфия:** рисование по стенам и полу в 3D, сохранение собственных символов, постепенное исчезновение чернил, смешивание и наложение рун, плавные объёмные шейдеры.

**Версия 0.3 — мир запоминает:** долговечные переписываемые печати, узоры на доспехах и постройках, древняя письменность подземелий, таблица «памяти мира», из-за которой часто используемые заклинания изменяют окрестности.

**Версия 0.4 — магия без готового списка:** пользовательские руны и обучение собственным символам, оригинальная система семантического композиционирования, магические автоматы и редактор ритуальных конструкций прямо в игре.
